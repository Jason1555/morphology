# Морфология изображений

Настольное приложение на Python (Tkinter + OpenCV + NumPy + Pillow) для
морфологической обработки, фильтрации и пользовательской свёртки
изображений в градациях серого. Архитектура — строгий MVC.

## Возможности

- Открытие PNG/JPEG/BMP/TIFF с автоматическим преобразованием в градации
  серого (BGR→Gray, BGRA сводится с чёрным фоном).
- 7 морфологических операций: эрозия, дилатация, открытие, закрытие,
  градиент, Top Hat, Black Hat — с настраиваемым структурным элементом,
  якорем и итерациями.
- Фильтры: резкость (сила 0–5), размытие в движении (длина/угол), тиснение
  (Emboss), медианный фильтр (нечётное ядро).
- Пользовательская свёртка: ядро до 31×31, делитель/автонормализация,
  bias, 5 типов границ, 6 предустановок.
- Редактор структурного элемента (Canvas-сетка до 101×101): рисование
  перетаскиванием, якорь в любой ячейке, 17 предустановок, отражения,
  повороты, сдвиги, сохранение/загрузка JSON/NPZ.
- История: Undo/Redo, переход к любому состоянию, возврат к оригиналу,
  корректное ветвление (redo-хвост отбрасывается).
- Тёмный русскоязычный интерфейс: исходник и результат рядом, зум,
  прокрутка, статусбар.

## Интерфейс

- Слева — категории: Морфология / Фильтры / Свёртка / История.
- Справа — панель параметров выбранной категории и список истории.
- По центру — «Исходное изображение» и «Результат» с кнопками −/+/Вписать
  (масштаб Ctrl+колесо, прокрутка — колесо мыши).
- Вверху — панель: Открыть, Сохранить, Отменить, Повторить, К оригиналу,
  редакторы элемента и ядра.
- Внизу — строка состояния. Долгие операции идут в фоне, кнопки
  блокируются на время обработки.

## Морфологические операции

1. Откройте изображение (Файл → Открыть).
2. Категория «Морфология» → выберите операцию (например, Opening).
3. Выберите форму элемента или откройте редактор для своей маски.
4. Задайте размер (W/H) и якорь, для эрозии/дилатации — итерации.
5. «Применить операцию» — результат добавится в историю.

Якорь передаётся в OpenCV как `anchor=(x, y)`. Пустой элемент отклоняется
с понятной ошибкой до запуска обработки.

## Редактор структурных элементов

- Размер 1×1 … 101×101, независимые ширина/высота, существующие ячейки
  сохраняются при resize, якорь корректируется.
- Сетка на `tkinter.Canvas` (без виджетов на ячейку): клик/перетаскивание
  рисует, инструменты — переключение/рисование/стирание/якорь.
- Счётчики: размер, число активных ячеек, якорь, координаты под курсором.
- 17 предустановок рассчитываются под текущие размеры (включая 101×101).
- Отражения, повороты 90/180/270 (с обменом размеров), сдвиги.
- Сохранение/загрузка JSON и NPZ (маска + размеры + якорь).
- Кнопки OK (принять), Отмена, Сохранить/Загрузить в файл.

## Ядра свёртки

- Редактор: строки/столбцы 1…31, коэффициенты — целые/дробные/отрицательные.
- Делитель вручную (≠ 0) или автонормализация по сумме; bias; граница
  (default/replicate/reflect/isolated/constant).
- Предустановки: резкость, размытие, границы H/V/диагональ, тиснение.
- Порядок вычислений: `filter2D(float32, kernel/divisor) + bias`,
  клип 0…255 только в конце — отрицательные промежуточные значения
  не обрезаются раньше времени.
- Кнопка «Открыть ядро тиснения в редакторе» копирует emboss-ядро
  (bias 128) для ручной правки.

## История обработки

- Каждая операция: название + параметры + копия результата.
- Undo/Redo, клик по записи для перехода, «К оригиналу» — новая запись.
- Новая операция после отката отбрасывает redo-ветку (предсказуемо).
- Хранится до 30 состояний (защита от расхода памяти), копии через
  `ndarray.copy()` — старые кадры не мутируются.

## Архитектура (MVC)

- `app/models/` — данные и математика, без Tkinter: изображение, история,
  морфология, фильтры, свёртка, SE-модель, kernel-модель.
- `app/views/` — только отображение: главное окно, просмотры, редакторы,
  история, диалоги. Алгоритмов обработки нет.
- `app/controllers/` — связь Model↔View: параметры из UI, запуск моделей
  в фоне, история, ошибки в messagebox. Математику не дублирует.
- `app/utils/` — `image_io` (grayscale load/save), `validators`.
- `main.py` — только сборка объектов и `mainloop()`.

## Ограничения

- Только градации серого (цвет не обрабатывается — конвертируется при
  открытии). Внутреннее представление — `uint8` массив `(H, W)`.
- История ограничена 30 состояниями.
- Undo внутри редактора SE отсутствует (Undo — на уровне операций).
